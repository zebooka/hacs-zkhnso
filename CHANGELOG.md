# История изменений

Все существенные изменения этого проекта документируются в этом файле.

## В разработке

### Исправлено

- Тарифы используют единицы стоимости за единицу ресурса, например `RUB/m³` и `RUB/kWh`, для совместимости с Energy Dashboard.
- Работа с CHANGELOG.md при выпуске новой версии.

## v1.0.0

### Добавлено

- Расширено тестовое покрытие parser, API-клиента и сенсоров.
- Новые инструкции в AGENTS.md касательно тестов и CHANGELOG.
- Добавлен GitHub Actions workflow для запуска тестов без Docker.
- Описание создания шаблона сенсора и таблица коээфициентов для подогрева теплоносителя.

### Исправлено

- Тарифы с одинаковыми названиями больше не перезаписывают друг друга.
- Значение тарифа берётся из поля `rate_per_unit` вместо `rate`.

## v0.3.0

### Добавлено

- Команда `make version X.Y.Z`
- CHANGELOG.md
- Инструкции для агентов в AGENTS.md

### Изменено

- Рефакторинг API-клиента и координатора обновления данных.
- Рефакторинг сенсоров счётчиков и тарифов: они используют актуальные данные coordinator.
- Исправлены имена сущностей счётчиков и тарифов.
- Минимальная поддерживаемая версия Home Assistant повышена до 2024.12.

## v0.2.0

### Добавлено

- Номер лицевого счёта добавлен в имена сенсоров счётчиков и тарифов.
- Адрес лицевого счёта добавлен в название подключения.
- Добавлены корректные классы устройств для счётчиков электроэнергии и тепла.
- Добавлена отдельная классификация счётчиков воды и газа.
- Добавлены переводы шаблонов имён сущностей счётчиков и тарифов.
- Добавлена лицензия MIT.
- Добавлены графические ресурсы логотипа интеграции.
- Добавлены тесты обработки данных и проверки учётных данных.

### Изменено

- Рефакторинг обработки счётчиков и тарифов, нормализация единиц тарифов.
- Атрибуты тарифов изменены с `rate`/`tariff` на `norm`/`rate`.
- Улучшена обработка некорректных ответов удалённого сервиса.
- Улучшена работа изолированной HTTP-сессии и cookies.
- Учётные данные удалены из debug-логов; остаётся только идентификатор учётной записи.
- Обновлена документация по установке и использованию в README.
- Обновлены HACS workflow и конфигурация CI.
- Обновлены ссылки в manifest и объявления зависимостей.
- Улучшена проверка учётных данных и предотвращено раскрытие пароля в debug-логах.
- Улучшена обработка ошибок первого запроса.
- Улучшены единицы измерения и обработка числовых значений.
- Выполнен рефакторинг кода интеграции и конфигурации окружения разработки.

### Исправлено

- Исправлены метаданные manifest.
- Исправлена прозрачность логотипа.
- Исправлены опечатки в README.
- Минимальная поддерживаемая версия Home Assistant повышена до 2024.11.
- Исправлены проблемы HACS validation и CI.
- Логотип добавлен в README, исправлена конфигурация CI.

## v0.1.0

### Добавлено

- Создана первоначальная версия интеграции Home Assistant в рамках Hackathon 2025.
- Добавлена русскоязычная документация README.
- Добавлен первоначальный workflow проверки HACS.

### Изменено

- Исправлена конфигурация окружения разработки.

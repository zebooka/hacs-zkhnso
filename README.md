ZKHNSO integration for Home Assistant. Can be used for integrating housing services in Russian Federation, Novosibirsk oblast. 

Интеграция ЖКХНСО.рф для Home Assistant для получения информации о счетчиках и тарифах.

## Установка

### HACS

[![Откройте свой экземпляр Home Assistant и перейдите к репозиторию в магазине Home Assistant Community Store.](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=zebooka&repository=hacs-zkhnso&category=integration)

1. Откройте **HACS** в Home Assistant и выполните поиск **ЖКХНСО** (или воспользуйтесь кнопкой выше).
2. Откройте **ЖКХНСО**, выберите **Скачать** (Download) и подтвердите действие.
3. Перезапустите Home Assistant, а затем перейдите к разделу [Настройка](#Настройка).

### HACS: пользовательский репозиторий

1. В HACS откройте **⋮ → Пользовательские репозитории**.
2. Добавьте `https://github.com/zebooka/hacs-zkhnso` с типом **Integration**.
3. Найдите **ЖКХНСО** и установите интеграцию.
4. Перезапустите Home Assistant.
5. Добавьте интеграцию через **Настройки → Устройства и службы**.

### Ручная установка

1. Скопируйте папку `zkhnso` в папку `custom_components` в вашем Home Assistant.
2. Перезапустите Home Assistant.
3. Добавьте интеграцию через **Настройки → Устройства и службы**.

## Настройка

Эта интеграция может быть настроена через пользовательский интерфейс Home Assistant:

1. Откройте **Настройки → Устройства и службы**.
2. Нажмите `+ Добавить интеграцию`.
3. Поищите **ЖКХНСО**.
4. Заполните параметры учётной записи.

Используются логин и пароль от личного кабинета ЖКХНСО. Данные проверяются до создания интеграции. Если пароль изменился, Home Assistant предложит повторно пройти аутентификацию.

## Возможности интеграции

- Получать список активных счетчиков (вкл. серийный номер, тип счетчика, дата следующей поверки, текущее значение, дата предыдущей передачи показаний)
- Получать список тарифов и нормативов

Данные обновляются один раз в час. Интеграция создаёт сущности для показаний счётчиков и тарифов, доступных в личном кабинете на момент настройки.

## Подсчет трат по счетчикам

Чтобы подсчитать траты на воду в разделе **Энергия**, необходимо создать вручную сенсор типа шаблон (template sensor).
Это необходимо сделать так как в списке тарифов предоставляемых УК отсутствуют финальные значения на воду.
Например, стоимость горячей воды может считаться как
`тариф теплоносителя + норматив подогрева × тариф подогрева + тариф водоотведения`
или как `тариф горячей воды + тариф водоотведения`. Управляющие компании называют тарифы по-разному и зачастую
для подсчета стоимости воды приходится выбирать тарифы на содержание общего имущества. Примеры названий:
`ГВ НА СОИ (ПОДОГРЕВ)`,
`ГВ НА СОИ (ТЕПЛОНОСИТ)`,
`ГВ НА СОД-Е ОБЩ.ИМУЩ.`,
`ГОРЯЧЕЕ ВОДОСНАБЖЕНИЕ (ПОДОГРЕВ)`,
`ОТВЕД. СТОЧ. ВОД СОИ`,
`ХВ НА СОД-Е ОБЩ.ИМУЩ.`,
`ХОЛОДНОЕ ВОДОСНАБЖЕНИЕ`.

1. Откройте **Настройки → Устройства и службы**.
2. Откройте вкладку **Вспомогательное**.
3. Нажмите `+ Создать вспомогательный объект`.
4. В форме поиска ищите **Template**, выберите подтип **Сенсор**.
5. Укажите название, шаблон состояния, единицу измерения (RUB/m³), устройство (ЖКХНСО), шаблон недоступности в дополнительных настройках.

## Ограничения и устранение неполадок

- Интеграция работает только с личными кабинетами ЖКХНСО Новосибирской области.
- Если сайт ЖКХНСО недоступен, Home Assistant повторит подключение автоматически.
- После изменения состава счётчиков или тарифов перезагрузите интеграцию через **Настройки → Устройства и службы**, чтобы создать сущности для новых записей.
- Для удаления откройте страницу интеграции в **Настройки → Устройства и службы** и выберите **Удалить**.
